# AML Consultant LLC

Sitio web oficial de **AML Consultant LLC** ([amlconsultant.com](https://www.amlconsultant.com)).

Liderado por **Leo I. Rivera, CFE, CAMS, CAFCA**.  
Servicios de consultoría en cumplimiento normativo BSA/AML, pruebas independientes de los 5 pilares, implementación de sistemas de monitoreo y core bancario, y capacitación para instituciones financieras en Puerto Rico y Estados Unidos.

## Estructura del Proyecto

- `index.html` - Página principal
- `thankyou.html` - Confirmación de envío de formulario de contacto
- `css/styles.css` - Estilos globales y diseño responsive
- `js/main.js` - Lógica de navegación, animaciones interactivas y formularios
- `assets/img/` - Recursos visuales, logotipos de marca y logotipos de clientes
- `.cpanel.yml` - Configuración de despliegue automático para GreenGeeks / cPanel
